External native UI automation only. InputBridge.java uses Android UiAutomation and Accessibility ACTION_SET_TEXT on a specified editable resource, exercising the actual native TextInput and its React callbacks without IME readiness races. No activity, launcher entry, permissions or network code. The separate helper is12KB, self-signed with an ephemeral QA certificate and installed only on disposable emulators. It is not bundled into the product. Compiled with javac/D8/aapt2 against SDK36; manifest and Java source included for review.
