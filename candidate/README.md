Тестовий кандидат **0.1.29, збірка 59**. Автоматичний канал залишається на 0.1.28 (58).

Розширено динамічний пошук за адресними сервісами операторів, офіційними PDF, XLSX та пов’язаними публічними таблицями. Враховується підтверджена джерелом територія: будинок, вулиця або населений пункт. Чергу можна ввести чи виправити без посилання; ручна правка має пріоритет над автоматичним пошуком. Дані досліджених адрес не вбудовано в застосунок.

Перевірено: 190 Node-тестів, 51 перевірка React-екранів, 3 перевірки браузерних сценаріїв; актуальні документи також декодовано в Chromium. У перевірці коду з живими джерелами відтворено 16 додаткових раніше не знайдених черг. Це не новий аудит усієї вибірки в установленій APK.

APK успішно зібрано локально; номер пакета, версію та підпис перевірено. Сертифікат збігається з 0.1.28. **Нативне оновлення та збереження ручної правки в цій APK поки не підтверджені**: GitHub Actions не запускає завдання через білінг, а програмні емулятори без KVM мають збої самої Android. На Android 16 проблема виникла з попередньою 0.1.28; на Android 11 — до встановлення застосунку. Успішний нативний прогін не заявляється.

Цей кандидат доступний для ручного встановлення; автоматичне оновлення на нього не ввімкнено. Повне адресне покриття ще не забезпечене. Постійний сервер не потрібний і не розгортався. Запити операторам не надсилалися.
