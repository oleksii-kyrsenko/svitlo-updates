# Світло — обновления Android

Здесь публикуются только подписанные APK, сведения о версиях и сценарий публикации. Исходный код приложения остаётся в отдельном приватном репозитории.

Новая версия приложения проверяет `latest.json`, предлагает обновление, скачивает APK и запускает стандартный установщик Android. Обновление можно отложить; проверка всегда доступна в настройках. Перед установкой проверяются SHA-256, пакет, номер сборки и сертификат.

Готовые версии доступны в [Releases](https://github.com/oleksii-kyrsenko/svitlo-updates/releases). Устанавливайте новую APK поверх предыдущей версии, чтобы сохранить места и настройки.

Текущая версия: **0.1.7, сборка 21** — [скачать APK](https://github.com/oleksii-kyrsenko/svitlo-updates/releases/download/android-test-21/svitlo-test-21.apk), 72,7 МБ. Графики Черкасиобленерго загружаются автоматически без настройки сервера. Для населения Попівки учтена очередь 3.1 из официального перечня с указанием уровня покрытия. Изменение адреса заново запускает поиск очереди; очередь можно задать отдельно вручную. Добавлены локальные напоминания при закрытом приложении и фоновая проверка Android; частоту проверок определяет ОС. Постоянный сервер с remote push ещё не развёрнут. Остальные ежедневные интеграции пока не подключены.

В Android-эмуляторе проверены запуск, обновление со сборки 18 с сохранением адреса, настоящий официальный график, два запланированных напоминания и регистрация фонового задания. Устанавливайте поверх предыдущей версии, приложение не удаляйте и данные не очищайте. Затем откройте «Настройки → Включить уведомления». Вход в GitHub не нужен.
