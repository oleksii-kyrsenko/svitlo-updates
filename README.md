# Світло — обновления Android

Текущая версия: **0.1.15, сборка 33** — [скачать APK](https://github.com/oleksii-kyrsenko/svitlo-updates/releases/download/android-test-33/svitlo-test-33.apk), 72,9 МБ. Исходники приложения остаются приватными.

Поиск улиц понимает разный порядок слов, сокращения, инициалы и грамматические формы. Названия отображаются из Укрпошты; отдельного списка личных имён или поправок для конкретных улиц в сопоставителе нет. Неоднозначный адрес не получает придуманную очередь.

В выборе области Киев показан под Київська область, город выбирается отдельно. Внутренний код Киева и городской оператор сохранены. Город можно искать сразу после области. GPS, карта, ручной выбор дома и несколько мест доступны; новые места открываются пустыми.

Проверенное написание уже сохранённых адресов восстанавливается автоматически, с сохранением координат и ручной очереди. Индекс и автоматическая очередь запрашиваются по выбранному дому. Полнота данных зависит от источников и подключения оператора.

Обновление доступно в настройках приложения. Устанавливайте поверх предыдущей версии, без удаления и очистки данных. Проверяются пакет, версия, SHA-256 и сертификат.

Пройдены 103 проверки логики, 22 сценария React-интерфейса, карта и проверки подписанного APK на Android11/15: обновление из сборки31, сохранение места, чистый запуск, официальный график и локальное уведомление при закрытом приложении. Используются локальные напоминания Android и фоновое обновление; полного покрытия всех операторов пока нет.
